# Design prompts

Watch the pixels. Ignore filler speech.

For each relevant moment:

- Timestamp
- What is on screen (screens, chrome, mascot, widget)
- Motion (easing, distance, duration if visible)
- Typography / icon style (line vs filled, sizes)
- Why it would feel “not vibe-coded”
- For a screen recording of the user's app: jank, clipping, layout shift, missed states

Then: 3 concrete UI changes for the user's current product.
If a timestamp was given (e.g. t=75s), start there and stay in that chapter unless the question needs more.

## Question types

- Motion / page transition: duration, direction, bounce, overlay vs push
- Layout / spacing: margins, safe areas, tab bars
- Type and icons: line vs filled, sizes, weight
- Mascot / empty state / illustration
- Widgets and lock-screen vs home-screen
- Onboarding and App Store screenshot frames
- Visual bug in a screen recording: what breaks, when, what the UI should do instead
